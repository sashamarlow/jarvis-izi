# JARVIS / IZI — Telegram Web

Один вариант программы, один файл запуска. Внешний вид папки после скачивания:

```text
JARVIS-IZI/
├── start.cmd
└── app/
```

## Скачать и запустить

1. Скачай проект с GitHub через **Code → Download ZIP** или готовый архив выпуска.
2. **Полностью распакуй ZIP** в обычную папку, например на рабочий стол.
   Не запускай `start.cmd` прямо из окна архива и не копируй его отдельно от `app/`.
3. Дважды нажми `start.cmd`. При первом запуске локальный Python и библиотеки
   скачиваются автоматически в `app/.runtime/`. Интернет для этого обязателен.
   Python заранее устанавливать не нужно. Системный Python, PATH и постоянная
   политика PowerShell не изменяются; права администратора не запрашиваются.
4. Выбери `1` — тест без отправки, `2` — реальная отправка `+`, или `3` — выбор/изменение автора.
5. В отдельном окне Microsoft Edge войди в **свой** Telegram через QR-код:
   Telegram на телефоне → Настройки → Устройства → Подключить устройство.
   Если нужен пароль 2FA, вводи его только в Telegram Web.
6. Открой нужную группу, перейди к последним сообщениям, очисти поле ввода
   и отмени ответ/пересылку/редактирование. Вернись в консоль и нажми Enter.
7. При первом запуске для этой группы выбери автора: `1` — **по сообщению в беседе**,
   `2` — ручной ввод числового Telegram ID. При выборе по сообщению программа покажет
   до 15 последних загруженных входящих сообщений: имя, найденный ID и фрагмент текста.
   Введи номер сообщения нужного человека. Enter обновляет список; при необходимости
   прокрути беседу к его сообщению и обнови. После выбора вернись к последним сообщениям.
   При ручном вводе нужен ID человека, не @username, не телефон и не ID группы.
   `0` отменяет выбор без сохранения. Проверь группу и ID в подтверждении,
   затем введи `1`, чтобы сохранить настройку и начать выбранный режим, или `0` для отмены.
   Пустой ввод не включает отправку. В пункте `3` подтверждение только сохраняет
   автора: наблюдение и отправка не запускаются.

Поддерживаются **Windows 10/11 x64 и установленный Microsoft Edge**.
Если Edge отсутствует, запускатель покажет ссылку на его установку; сам браузер
он не устанавливает. Доступ к python.org, bootstrap.pypa.io, PyPI и Telegram
не должен блокироваться сетью/VPN. Windows ARM64, x86, Linux и macOS в этом
выпуске не поддерживаются. Корпоративные ограничения могут запрещать запуск скриптов.

Для завершения — Ctrl+C в консоли. Компьютер должен оставаться включённым и без сна,
а консоль и управляемый Edge — открытыми. Не переключай беседы и не печатай
в управляемом окне во время наблюдения. На телефоне и в обычном Telegram работать можно.

## Что делает программа

Сохранены оформление Amber, баннер JARVIS / IZI, выбор режима и подтверждение цифрой `1`.
Реагирует на **новые типовые текстовые объявления**: дата, запуск, гости,
смета персонала, положительное число барменов и дополнительные поля.
Отправляет отдельный `+`, не ответ на сообщение. Собственные и старые сообщения
игнорируются, повторные ID подавляются; тест и реальная отправка имеют отдельную историю.
Принимаются объявления **только от сохранённого Telegram ID автора в этой группе**.
Имя и @username для проверки не используются. Наличие и правильность аккаунта
по одному введённому числу не подтверждаются; если ID введён неверно, бот не сможет
реагировать на нужного человека. Выбор по сообщению извлекает ID из загруженной страницы;
перед выбором повторно проверяются отправитель, сообщение и беседа. Имя служит только
подсказкой, одинаковые имена не объединяются. Неопределяемые авторы в список не попадают.
Изменить автора можно через пункт `3`. Старые настройки с вручную введённым ID совместимы.
Для каждой другой группы задаётся отдельный автор. Без ID наблюдение не включается.
Если автор сообщения не определился по интерфейсу страницы, отправка блокируется
с предупреждением. Если данные автора догрузятся, новое сообщение проверяется снова,
пока оно не устарело. ID первоначального автора пересылки/цитаты не считается ID
отправителя; анонимная отправка от имени группы не подтверждает личность человека.
Перед кликом проверяются повторно автор и неизменность текста объявления.
При смене беседы, занятом черновике или неопределённом результате отправки
останавливается. Повторного клика после неопределённого результата нет.

Правила находятся в `app/rules.json`, изменения применяются после перезапуска.
Обнаружение событийное: `MutationObserver` замечает появление и изменения сообщений,
обрабатываются затронутые элементы. Постоянного обхода списка каждые 100 мс больше нет.
Сначала определяется автор: текст других участников не разбирается. Сохраняется
40 мс стабильности текста и автора, но это отдельный таймер, не ожидание очередного опроса.
Ожидание готовности кнопки и подтверждения отправки также работает по изменениям страницы
в одном обращении к браузеру. Раз в секунду проверяется состояние наблюдения без обхода
списка сообщений. Проверка правил остаётся локальной, без нейросетей или сетевых запросов.

В журнале отдельно показаны время от первого обнаружения на странице до клика,
подготовка сообщения (входит в это время) и ожидание подтверждения после клика.
Это не время от отправки старшим барменом и не доставка плюса всем участникам.
В тестовом режиме показывается время обнаружения/подготовки, клик не выполняется.
Подробный лог пишется после клика; запись защиты от дублей сохраняется перед ним.

Сравнение предыдущего и событийного вариантов: [результаты офлайн-замера](BENCHMARK.md).
Механизм уведомлений: [MutationObserver](https://developer.mozilla.org/en-US/docs/Web/API/MutationObserver).
Распознавание коротких объявлений пока не добавлено. Обновления Telegram Web могут потребовать адаптации программы;
скорость сети и первое место в очереди не гарантируются.

## Личные данные

Каждый пользователь входит самостоятельно. В скачиваемом архиве **нет авторизации,
выбранной беседы, журнала или истории другого пользователя**.

- `app/data/web-profile/` — локальный профиль с сохранённым входом.
- `app/data/web-group.json` — последняя подтверждённая беседа, подсказка при запуске.
- `app/data/web-authors.json` — выбранный Telegram ID автора для каждой настроенной беседы.
- `app/data/web-history.sqlite3` — история обработанных сообщений.
- `app/data/bot.log` — журнал работы.

`app/data/` даёт доступ к аккаунту. Не публикуй и не передавай эту папку.
Она, `.runtime/`, `.venv/` и кеши исключены через `app/.gitignore`.
Для отзыва доступа заверши соответствующую Web-сессию в Telegram → Настройки → Устройства.
Данные в этой папке не зашифрованы самой программой.

Не запускай одновременно разные копии программы: блокировка действует внутри
одной папки, а независимые копии могут отправить два плюса. Для владельца проекта
сохранённый профиль перенесён в `app/data/`; старая `telegram-auto-reply` — резервная копия.

## Проверка установки без Telegram

Из PowerShell в главной папке:

```powershell
.\start.cmd --setup-check --no-pause
```

Проверит/подготовит зависимости, но не запустит Edge и не прочитает профиль Telegram.
Проверка правил: `start.cmd --check-rules`. Превью: `start.cmd --preview`.
Настройка автора напрямую: `start.cmd --configure-author`.
При повреждении `web-authors.json` программа не сбрасывает файл и не включает
реакцию на всех участников: нужно исправить/восстановить настройки. Переименование
этого файла в резервную копию вручную позволит настроить авторов заново.

Для разработчика после первичной подготовки, из `app/`:

```powershell
.\.runtime\python\python.exe -X utf8 -m unittest discover -s tests -p test_core.py -v
.\.runtime\python\python.exe -X utf8 -m unittest discover -s tests -p test_rules.py -v
.\.runtime\python\python.exe -X utf8 -m unittest discover -s tests -p test_console_ui.py -v
.\.runtime\python\python.exe -X utf8 -m unittest discover -s tests -p test_launchers.py -v
.\.runtime\python\python.exe -X utf8 -m unittest discover -s tests -p test_authors.py -v
```

Эти тесты не запускают браузер. Полный набор дополнительно запускает Edge без
видимого окна на искусственной странице, не на реальном аккаунте.
На компьютере владельца может использоваться ранее созданное `app/.venv/`:
это локальный запасной путь запуска, в скачиваемую версию он не входит.

Замер текущей версии без Telegram (Edge без видимого окна, искусственная страница,
все сетевые запросы тестового браузера заблокированы):

```powershell
.\.runtime\python\python.exe -X utf8 tests\benchmark_web.py --samples 40
```

Для сравнения с прежней версией добавь `--baseline "путь\к\старому\web_dom.js"`.
Сравнение предназначено для предыдущей версии с опросом 100 мс и прежним интерфейсом
`arm/poll/preflight/commit/acknowledged`. Бенчмарк использует временную историю,
не читает профиль Telegram и не отправляет реальные сообщения.

## Архив для распространения

`app/package_release.ps1` собирает архив по явному списку исходных файлов, без
`data/`, `.venv/`, `.runtime/`, логов и кешей. В него попадают только `start.cmd` и `app/`.
Например, из главной папки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\app\package_release.ps1 -Destination "$env:TEMP\JARVIS-IZI-release.zip"
```

Python и загрузчик библиотек берутся с официальных сайтов по закреплённым
версиям и SHA-256; несовпадающий файл не запускается. Библиотеки устанавливаются
из PyPI в локальную папку. Техническая основа:
[Python embeddable](https://docs.python.org/3/using/windows.html#the-embeddable-package)
и [pip zipapp](https://pip.pypa.io/en/stable/installation/#standalone-zip-application).
