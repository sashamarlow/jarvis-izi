# Офлайн-замер событийного обнаружения

Дата: 9 октября 2026. Windows, установленный Microsoft Edge, headless,
Python 3.14.6 и закреплённые зависимости программы. Скрипт: `tests/benchmark_web.py`.

| От появления готового сообщения на искусственной странице до клика | Предыдущая версия, опрос 100 мс | Событийная версия |
| --- | ---: | ---: |
| Медиана | 180,95 мс | 62,70 мс |
| 95-й процентиль | 239,30 мс | 68,90 мс |
| Минимум | 134,00 мс | 57,80 мс |
| Максимум | 245,90 мс | 70,30 мс |
| Измерений | 40 | 40 |

В этом сравнении медиана уменьшилась примерно в 2,9 раза (на 65%).
Распознавание одного типового объявления существующими правилами Python заняло
в среднем 0,0146 мс за отдельные 5000 вызовов; перенос правил в JavaScript не выполнялся.

Методика:

- Обе версии проверялись в одном процессе браузера, в свежих страницах без профиля.
- Запуски чередовались; для каждой пары использовалась одинаковая задержка появления
  сообщения от 1 до 100 мс, генератор с seed 42.
- По три разогревочных запуска каждой версии исключены из статистики.
- Сообщение добавлялось сразу с текстом и данными автора. В обеих версиях сохранена
  проверка стабильности 40 мс. Готовность кнопки и подтверждение имитировались локально.
- Измерение выполнено часами браузера от вставки сообщения до обработчика клика.
  Включены проверка автора, Python-правила, реальная запись защиты от дублей в
  временную SQLite, заполнение поля и проверки перед кликом.
- Весь сетевой доступ тестовых страниц заблокирован. Браузер запускался без видимого
  окна. Рабочая авторизация и пользовательская история не использовались.

Это измерение локальной обработки, а не реального чата. Здесь нет задержек Telegram,
VPN, доставки сообщения в Web-клиент и получения плюса другими участниками.
Догрузка текста/автора, фоновые ограничения браузера и нагрузка компьютера могут
увеличить время. Значения не являются обещанием скорости в реальной беседе.

Скрипт печатает JSON с результатами и может повторить замер текущего релиза:

```powershell
.\.runtime\python\python.exe -X utf8 tests\benchmark_web.py --samples 40
```

Для сравнения нужен сохранённый `web_dom.js` предыдущего релиза:

```powershell
.\.runtime\python\python.exe -X utf8 tests\benchmark_web.py --samples 40 --baseline "C:\папка\предыдущая-версия\web_dom.js"
```
